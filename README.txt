DRAGON'S GRIND — INSTALLABLE PWA

To install on Android:
1. Upload every file in this folder to a free GitHub repository.
2. In GitHub: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3. Open the published HTTPS GitHub Pages URL in Chrome.
4. Choose Install app / Add to Home screen from the browser menu.

PWA installation and offline caching require HTTPS or localhost. Opening index.html directly is only a preview.

Progress is saved locally in this browser/device. Use Settings > Export backup regularly.
Cloud sync is not configured in this edition; it requires a backend account and credentials.
